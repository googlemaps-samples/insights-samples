# Custom Satellite Embeddings data access in Earth Engine

In this guide, learn how to use Google Earth Engine to access Cloud-Optimized GeoTIFFs (COGs) in Google Cloud Storage.  
The demonstration uses six monthly satellite embeddings images in an agricultural area of the California, USA central valley.

This guide demonstrates:

- Making COG-backed images and image collections in Earth Engine.
- Dynamically loading COGs as images in Earth Engine.
