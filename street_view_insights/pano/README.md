# Panorama and Full Scene Notebooks

This directory contains Jupyter notebooks demonstrating analysis and processing of full scene and panoramic street view imagery using Gemini models.

## Notebooks

- **[Analyze Sequential Images](file:///Users/sarthakgy/Desktop/insights-samples/street_view_insights/pano/analyze_sequential_images.ipynb)**: Demonstrates how to analyze sequences of Street View images to detect and understand changes or analyze surroundings sequentially.
- **[House Image Discovery with Cost](file:///Users/sarthakgy/Desktop/insights-samples/street_view_insights/pano/house_image_discovery_with_cost.ipynb)**: Demonstrates how to spatially filter, visually analyze, and cluster street-view imagery to discover target houses and calculate API costs using Gemini.
- **[Surface Material Detection](file:///Users/sarthakgy/Desktop/insights-samples/street_view_insights/pano/surface_material_detection.ipynb)**: Showcases how to classify road surface material (Paved, Gravel, Mud, Dirt) from panorama or full scene imagery.
- **[Agentic Roof Edge Detection](file:///Users/sarthakgy/Desktop/insights-samples/street_view_insights/pano/agentic_roof_edge_detection.ipynb)**: Demonstrates a pipeline to fetch imagery, perform lens distortion correction, and trace visible roof edges using Gemini 3.5 Flash and code execution.
